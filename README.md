# TWOZERO Animator

Редактор покадровой анимации для пиксельного персонажа TWOZERO (16×16).
Один HTML-файл, без сборки и зависимостей.

**→ [vankrav.github.io/twozero-animator](https://vankrav.github.io/twozero-animator/)**

Локально — просто открыть файл, интернет не нужен:

```
open index.html
```

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Сам редактор. Всё в одном файле, работает офлайн. |
| `demo/` | [Как встроить персонажа на сайт](https://vankrav.github.io/twozero-animator/demo/) — четыре способа с живыми примерами и кодом. |
| `AGENTS.md` | Инструкция для ИИ-агента: как делать анимации из терминала, без браузера. |
| `tools/` | `build.mjs` пересобирает производные файлы, `preview.mjs` показывает клип ASCII-графикой в терминале. |
| `source/TWOZERO.svg` | Исходный спрайт, из которого снята геометрия. |
| `twozero-sprite.js` | Готовый модуль: геометрия спрайта, отрисовка в canvas, класс `Animator` и все клипы. Браузер и Node. |
| `animations.json` | Канонический формат: геометрия + все клипы. Это то, что можно отдать мне, чтобы я анимировал персонажа сам. |
| `clips/*.svg` | Каждый клип как самодостаточный анимированный SVG (SMIL). Работает в `<img>`, в CSS-фоне, в README. |
| `clips/*.gif` | То же в GIF, 8× (128×128). |

## Разбор исходного SVG

Персонаж собран из частей, каждая с фиксированным набором состояний:

| Часть | Состояния | Клетки |
|---|---|---|
| тело | всегда | строки y3–y10, глазницы 2×2 вырезаны |
| рука L | `down` / `up` / `off` | `(2,8–11)` / `(1,6–8)+(2,8)` |
| рука R | `down` / `up` / `off` | `(13,8–11)` / `(14,6–8)+(13,8)` |
| нога L | `down` / `up` / `off` | `(6,11–13)` / `(6,10–12)` |
| нога R | `down` / `up` / `off` | `(9,11–13)` / `(9,10–12)` |
| глаз L | `tl` `tr` `bl` `br` / `off` / `shut` | зрачок внутри глазницы `x5–6, y6–7` |
| глаз R | `tl` `tr` `bl` `br` / `off` / `shut` | зрачок внутри глазницы `x9–10, y6–7` |

Глазницы в исходнике — дырки в теле, поэтому у глаза три режима:
`tl…br` — зрачок в одном из углов, `off` — зрачка нет и глазница пустая,
`shut` — глазница залита цветом тела, то есть глаз закрыт. На `shut` держится моргание.

Спрайт симметричен относительно вертикальной оси, поэтому `flip` — честное зеркало
без отдельных ассетов: `x → 15 − x`.

Сверх исходника у кадра есть `ox`/`oy` (сдвиг всего персонажа в пределах кадра 16×16,
для подпрыгивания и тряски) и `hold` — сколько тиков держится кадр.

## Управление

Позу можно ставить **кликом прямо по спрайту**: клик по руке или ноге переключает
её вверх/вниз, клик по четверти глазницы ставит туда зрачок. Панель справа делает
то же самое явно, плюс даёт состояния, которых на спрайте не ткнёшь:
`off` для конечности (часть скрыта) и `off` / `shut` для глаза.

| Клавиша | Действие |
|---|---|
| `space` | play / pause |
| `←` `→` | предыдущий / следующий кадр |
| `1` `2` `3` `4` | рука L, рука R, нога L, нога R |
| `W` `A` `S` `D` | взгляд (по осям, вторая ось сохраняется) |
| `E` | глаза по кругу: `off` → `shut` → обратно к зрачку |
| `F` | зеркало |
| `N` | дублировать кадр |
| `⌫` | удалить кадр |
| `[` `]` | длительность кадра |
| `⇧` + стрелки | сдвиг спрайта |
| `P` | открыть playground |

Кадры в таймлайне перетаскиваются мышью. Всё сохраняется в `localStorage`;
кнопка `reset` возвращает встроенную библиотеку.

## Playground

Кнопка `Playground` в шапке (или `P`) открывает площадку, где персонажем можно
порулить: стрелками бегать, `↑` прыгать. Клип выбирается сам по состоянию —
стоит, бежит или в воздухе, — так что анимацию видно в деле, а не на месте.

| Клавиша | Действие |
|---|---|
| `←` `→` | бежать (зеркало переключается по направлению) |
| `↑` | прыжок; отпустил раньше — прыжок короче |
| `⇧` | бежать быстрее |
| `R` | вернуть на старт |
| `esc` | выход в редактор |

Три списка в шапке площадки задают, какой клип играет в каком состоянии
(по умолчанию `idle` / `run` / `jump`). Меняются на лету — удобно смотреть,
как читается только что нарисованный цикл. В воздухе клип не проигрывается:
берётся один самый «раскрытый» кадр, а высоту задаёт физика.

Мир — 192×84 пикселя спрайта, пять площадок. Подъём прыжка ~30 px, поэтому
каждая ступень поднята не выше чем на 20 px над предыдущей, а разрывы по
горизонтали меньше 24 px — столько персонаж пролетает за время полёта.

## Встроенные клипы

`idle` · `blink` · `walk` · `run` · `wave` · `windmill` · `look-around` · `jump` · `dance` · `scan`

Клипы, добавленные в библиотеку позже, подмешиваются к сохранённым при загрузке —
свои правки не теряются, а удалённые вручную клипы не воскресают.

## Формат

```jsonc
{
  "format": "twozero-anim/1",
  "size": 16,
  "palette": { "bg": "#DB0000", "fg": "#3B0000" },
  "parts": { "body": [[x,y],…], "armL": { "down": […], "up": […] }, … },
  "clips": {
    "run": {
      "fps": 12,
      "loop": true,
      "frames": [
        { "armL":"down", "armR":"up", "legL":"up", "legR":"down",
          "eyeL":"br", "eyeR":"br", "ox":0, "oy":0, "flip":false, "hold":1 }
      ]
    }
  }
}
```

`hold` — длительность кадра в тиках; тик равен `1000 / fps` мс.

## Использование модуля

```html
<canvas id="c" width="128" height="128"></canvas>
<script src="twozero-sprite.js"></script>
<script>
  new TWOZERO.Animator(document.getElementById('c'), 'run').start();
</script>
```

`Animator` подгоняет размер canvas под целое число пикселей на клетку.
Полезное наружу: `TWOZERO.clips`, `TWOZERO.cells(pose)` → список закрашенных клеток,
`TWOZERO.draw(ctx, pose, scale, opts)`, методы `.set(name)`, `.start()`, `.stop()`, `.step(dt)`.
В `opts` можно передать `{ alpha: true }` (прозрачный фон) и свои `bg` / `fg`.

## Пересборка

`index.html` — источник правды: в нём и геометрия, и библиотека клипов.
Всё остальное выводится из него:

```
node tools/build.mjs        # twozero-sprite.js, animations.json, clips/, demo/assets/
node tools/preview.mjs run  # показать клип ASCII-графикой в терминале
```

Сгенерированные файлы руками не правят. Подробности — в [AGENTS.md](AGENTS.md).

## Экспорт

- **JSON** — весь проект целиком, плюс импорт обратно.
- **SVG** — анимация на SMIL, один файл, зацикливается сама.
- **GIF** — задержки берутся из `fps` и `hold`; масштаб 1×…32×; прозрачность по тумблеру `alpha bg`.
- **PNG sheet** — горизонтальная полоса кадров + JSON с длительностями.
- **JS-модуль** — `twozero-sprite.js` с текущими клипами внутри.
