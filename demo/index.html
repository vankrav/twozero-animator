Как встроить персонажа на сайт

Всё ниже — файлы из кнопки Export в редакторе. Каждый пример живой: слева работает прямо на этой странице, справа — код, который надо скопировать. Ничего собирать не нужно.

СпособФайловКогда брать
SVG1 По умолчанию. Легче всех, масштабируется без потерь, зацикливается сам.
GIF1 Куда SVG не пускают: письма, Telegram, чужие CMS.
PNG-лист + CSS1 Нужно управлять анимацией из CSS: пауза, скорость, запуск по :hover.
JS-модуль1 Нужно менять анимацию из кода: реакция на действия, смена клипов.

Анимированный SVGпроще некуда

Одна строка. Файл самодостаточный: анимация внутри него, зацикливается сама, JS не нужен. Масштабируется без потерь — image-rendering не нужен, в экспорте уже стоит shape-rendering="crispEdges".

<img src="run.svg" width="128" alt="TWOZERO">

Тот же SVG фономбез лишнего тега

Если персонаж — украшение, а не содержимое, ему не место в <img>. Фон не читается скринридером и не мешает разметке.

на светлом фоне страницы
.mascot {
  width: 128px;
  height: 128px;
  background: url("idle.svg") center/contain no-repeat;
}

PNG-лист и CSS steps()анимация из css

Кадры лежат в ряд одной картинкой, а steps() двигает фон рывками — ровно по кадру. Лист 1× весит 206 байт, размер задаётся через background-size.

Числа берутся из клипа: 4 кадра, 12 fps → цикл 0.333s, ширина фона — 4 × 128 = 512px. Способ требует, чтобы у всех кадров была одинаковая длительность: steps() не умеет держать один кадр дольше других. У run и walk так и есть, у idle — нет.

run-sheet.png · 206 Б
.run {
  width: 128px;
  height: 128px;
  background: url("run-sheet.png") no-repeat;
  background-size: 512px 128px;   /* 4 кадра × 128 */
  image-rendering: pixelated;
  animation: run-cycle .333s steps(4) infinite;
}
@keyframes run-cycle {
  to { background-position: -512px 0 }
}

JS-модульнаведи на него мышь

twozero-sprite.js — 9 КБ, без зависимостей: внутри геометрия спрайта и все клипы. Даёт менять анимацию на лету. Наведи мышь на персонажа справа — он переключится с idle на windmill.

idle ⇄ windmill по наведению
<canvas id="hero" width="128" height="128"></canvas>
<script src="twozero-sprite.js"></script>
<script>
  // alpha — прозрачный фон, fg — свой цвет спрайта
  const cv = document.getElementById('hero');
  const a  = new TWOZERO.Animator(cv, 'idle', {
    alpha: true, fg: '#3B0000'
  }).start();

  cv.onmouseenter = () => a.set('windmill');
  cv.onmouseleave = () => a.set('idle');
</script>

Доступные клипы — TWOZERO.clips. Ещё есть a.stop(), TWOZERO.cells(pose) (список закрашенных клеток) и TWOZERO.draw(ctx, pose, scale, opts), если хочется рисовать самому.

Что легко упустить

image-rendering: pixelated Нужен растру — GIF и PNG. Без него браузер размывает пиксели при увеличении. SVG в этом не нуждается: он векторный.
Прозрачный фон Тумблер alpha bg на сцене редактора. Без него в экспорт уезжает красный квадрат — на чужом фоне это заметно.
Целое число пикселей Размер кратный 16 (128, 160, 256) — спрайт ложится ровно. На 150px пиксели поедут неравномерно.
steps() и длительности CSS-способ требует одинаковой длительности у всех кадров. Для клипов с разными hold берите SVG или GIF.
