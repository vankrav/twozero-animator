# Инструкция для агента

Репозиторий — редактор покадровой анимации пиксельного персонажа TWOZERO 16×16.
Этот файл описывает, как добавлять анимации **без браузера**, из терминала.

## Главное правило

`index.html` — единственный источник правды. В нём и геометрия спрайта, и библиотека
клипов (функция `builtinClips()`). Всё остальное генерируется:

```
index.html  ──node tools/build.mjs──▶  twozero-sprite.js
                                       animations.json
                                       clips/*.svg  clips/*.gif
                                       demo/assets/*
```

**Не редактируй сгенерированные файлы руками** — следующая сборка их перезапишет.
Правь `builtinClips()` в `index.html` и запускай сборку.

## Модель спрайта

Сетка 16×16, начало координат в левом верхнем углу. Персонаж собран из частей,
у каждой — фиксированный набор состояний. Промежуточных положений нет: это не
скелетная анимация, а перебор готовых поз.

| Часть | Ключ | Состояния |
|---|---|---|
| рука левая | `armL` | `down` · `up` · `off` |
| рука правая | `armR` | `down` · `up` · `off` |
| нога левая | `legL` | `down` · `up` · `off` |
| нога правая | `legR` | `down` · `up` · `off` |
| глаз левый | `eyeL` | `tl` `tr` `bl` `br` · `off` · `shut` |
| глаз правый | `eyeR` | то же |

Тело рисуется всегда. Глазницы — дырки в теле: `off` оставляет дырку пустой,
`shut` заливает её цветом тела (закрытый глаз), `tl…br` ставит зрачок в угол.

Спрайт симметричен относительно вертикальной оси, поэтому `flip` — честное
зеркало (`x → 15 − x`), отдельных ассетов для взгляда влево не нужно.

## Формат кадра и клипа

```js
// f(armL, armR, legL, legR, eyeL, eyeR, ox = 0, oy = 0, flip = false, hold = 1)
// D и U — сокращения для 'down' и 'up'
"мой-клип": { fps: 8, loop: true, frames: [
  f(D, U, U, D, "br", "br"),
  f(D, D, D, D, "br", "br", 0, -1),
]},
```

| Поле | Значение |
|---|---|
| `fps` | целое 1…60. Тик длится `1000 / fps` мс |
| `loop` | `true` — зациклить, `false` — сыграть один раз |
| `hold` | сколько тиков держится кадр, целое ≥ 1 |
| `ox` `oy` | сдвиг всего персонажа в кадре, целые. `oy` отрицательный — вверх |
| `flip` | зеркало по горизонтали |

**Границы сдвига.** Спрайт обрезается краем кадра 16×16. Безопасно:
`oy` от −3 до +2; `ox` от −2 до +2 при опущенных руках и от −1 до +1 при поднятых
(поднятая рука занимает столбец 1 слева и 14 справа).

## Как добавить анимацию

1. Открой `index.html`, найди `function builtinClips()` и добавь клип в
   возвращаемый объект по формату выше.
2. Посмотри, что получилось:
   ```
   node tools/preview.mjs мой-клип
   ```
   Выведет все кадры ASCII-графикой рядом друг с другом, длительность цикла
   и список того, что вообще меняется от кадра к кадру.
3. Пересобери производные файлы:
   ```
   node tools/build.mjs
   ```
   Сборка сначала проверяет все клипы и падает с внятной ошибкой, если состояние
   написано с опечаткой или `hold` не целый.

`node tools/preview.mjs` без аргументов покажет список клипов с их параметрами.
`node tools/preview.mjs мой-клип --gif` дополнительно положит GIF в `/tmp`.

## Что читается как движение

Состояний всего два на конечность, поэтому плавных дуг не бывает — движение
держится на чередовании и на сдвиге. Проверено на встроенных клипах:

- **Бег и ходьба.** Чередуй противоположные пары: левая рука вниз + правая вверх,
  левая нога вверх + правая вниз, затем наоборот. Между ними ставь кадр, где всё
  опущено, со сдвигом `oy: -1` — это проходная фаза, именно она продаёт бег.
- **Прыжок.** Обе ноги `up` сами по себе почти не видны (подъём всего 1 px).
  Высоту задаёт `oy`, а `up` только доигрывает подобранные ноги.
- **Направление.** Взгляд — единственное, что показывает, куда смотрит персонаж.
  Бежит вправо — оба зрачка в `br` или `tr`. `flip` разворачивает всё разом.
- **Моргание.** `shut` на 1–2 тика. Дольше читается уже как «спит».
- **Пустой взгляд.** `off` убирает зрачки, оставляя пустые глазницы.
- **Темп.** 4–6 fps для покоя и осматривания, 6–8 для ходьбы, 10–14 для бега
  и вращения руками.
- Если клип понадобится встраивать через CSS `steps()`, у всех кадров должна быть
  одинаковая `hold`. `preview.mjs` пишет об этом в конце вывода.

## Использовать анимации в коде

```js
import fs from "node:fs";
const data = JSON.parse(fs.readFileSync("animations.json", "utf8"));
data.clips["run"].frames;     // массив поз
data.parts;                    // геометрия: какие клетки у какого состояния
```

В браузере — `twozero-sprite.js` (без зависимостей, 9 КБ):

```html
<canvas id="c" width="128" height="128"></canvas>
<script src="twozero-sprite.js"></script>
<script>new TWOZERO.Animator(document.getElementById('c'), 'run').start();</script>
```

Наружу торчат `TWOZERO.clips`, `TWOZERO.cells(pose)` (список закрашенных клеток),
`TWOZERO.draw(ctx, pose, scale, opts)` и класс `Animator` с методами
`set(name)` · `start()` · `stop()` · `step(dt)`.

Способы вставки на страницу с живыми примерами — в `demo/index.html`.

## Границы

- Новые **позы** (например, полусогнутая рука) добавить нельзя, не дорисовав их
  в геометрии: `PARTS` и `EYES` в `index.html` задают конкретные клетки. Это
  правка спрайта, а не анимации.
- Автотесты редактора (Playwright) в репозиторий не входят — они завязаны на
  локальную установку браузера. Проверка клипов из `tools/` от браузера не зависит.
- `tools/lib.mjs` вытаскивает функции из `index.html` по именам. Если переименуешь
  `builtinClips`, `poseCells`, `clipToSVG`, `clipToGIF`, `jsModule` или
  `projectJSON` — поправь и список в `lib.mjs`.
